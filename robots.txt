# ============================================================
# U.P. System Cash Office Integrated Web System
#
# This is an internal portal for authorized personnel. Nothing here
# should appear in a search result: the sign-in page is a phishing
# template if it is copied, the registration page collects names and
# LBP account numbers, and neither is useful to anyone who arrived
# from a search engine rather than from the Cash Office.
#
# This file is a request, not a control. It is honoured by the major
# crawlers and ignored by anything hostile — the enforcement is
# X-Robots-Tag in vercel.json plus the <meta name="robots"> tag on
# each page. Treat all three as the same decision written down in the
# three places that each catch a different reader.
# ============================================================
